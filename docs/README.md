# Project documents

- [project_proposal.pdf](project_proposal.pdf): the group's original proposal,
  moved from `project_files/` without changing its contents.
- [project_requirements.md](project_requirements.md): submission formats, milestones and dataset recommendations.
- [data_dictionary.md](data_dictionary.md): expected SSA fields, units and interpretation rules.
- [data_audit.md](data_audit.md): the 9 November acquisition-audit attempt and its remaining provenance checks.
- [project_understanding.md](project_understanding.md): project understanding
  and a verified local inventory snapshot from 9 November 2026.
- [course_requirements.md](course_requirements.md): course description supplied
  by the user, deadlines, grading, submission formats and dataset recommendations.
- [data_inventory/README.md](data_inventory/README.md): verified state-file
  coverage, checksums, record counts and unresolved acquisition provenance.
- [archive/](archive/): the original PyCharm example, retained for reference.

Store course instructions and notes explaining preparation decisions here when
they are available. Record the reason for a decision and the evidence behind
it, so another group member can understand and reproduce the work.

The data-source guide is in [data/README.md](../data/README.md). Code and
analysis belong in `src/` and `notebooks/`; report sources and selected outputs
belong in `reports/`.
