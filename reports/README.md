# Reports and figures

This folder is reserved for report sources and outputs once the group produces
them. No report, analytical results or conclusions have been generated yet.

Place selected figures in `figures/`, using descriptive names. Each figure
should be traceable to the notebook or script that generated it. Keep datasets
in `data/` and working notes in `docs/`.

The group will introduce the lecturer's report template and Quarto when the
report task begins. Rendered `_site/` output and `.quarto/` caches are ignored.
